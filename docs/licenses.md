## Fonts

All fonts are self-hosted. The source files are in `fonts-src/` together with their license texts. `npm run fonts:build` subsets them to the characters Margin needs and converts them to woff2. Subsetting and format conversion are modifications the SIL OFL 1.1 explicitly allows. None of these fonts declares a Reserved Font Name, so the subsets keep their original names.

| Font | Use | License | Source | Copyright |
|---|---|---|---|---|
| Caveat | Handwriting (default) and the wordmark/favicon outlines | SIL OFL 1.1 (`fonts-src/Caveat-OFL.txt`) | github.com/googlefonts/caveat, via github.com/google/fonts `ofl/caveat` | © 2014 The Caveat Project Authors |
| Playpen Sans | "Clearer handwriting" option | SIL OFL 1.1 (`fonts-src/PlaypenSans-OFL.txt`) | github.com/TypeTogether/Playpen-Sans, via github.com/google/fonts `ofl/playpensans` | © 2023 The Playpen Sans Project Authors |
| Inter | Small UI and attribution text | SIL OFL 1.1 (`fonts-src/Inter-OFL.txt`) | github.com/rsms/inter, via github.com/google/fonts `ofl/inter` | © 2020 The Inter Project Authors |

**Wordmark and favicon.** These are glyph outlines of Caveat (OFL), generated by `scripts/fonts/build-fonts.mjs` and `scripts/brand/build-icons.mjs`. Using a font's outlines in a logo is permitted under the OFL. The OFL only governs redistributing the font itself, not artwork made with it.

## Textures and sounds

The paper grain and fibres are procedural SVG noise (`feTurbulence`) defined inline in `src/theme/tokens.css`. They are original to Margin, contain no third-party assets, and fall under the MIT license.
